# AtlasForge

遊戲圖集(sprite atlas)裁切與重排工具。純前端、單一 HTML 檔、離線可用,**不上傳任何圖片**,所有運算在瀏覽器 Canvas 完成。

## 用法

直接用瀏覽器打開 `index.html` 即可(Chrome / Edge)。

1. **① 輸入來源**
   - `已打包大圖`:一張已排成格狀的圖集,工具會先切格。
   - `單張 frame`:一次拖入多張獨立 PNG,各自處理。
   - 載入方式:**拖放**、**貼上 (Ctrl+V,從剪貼簿)**、或點擊選擇檔案。

   **背景 / 內容判斷(參數區)**:決定「哪裡算空白」。
   - `自動`(預設):看邊框像素——透明背景 → 用 alpha;不透明黑底 → 用亮度。
   - `透明`:強制用 alpha(適合去背 PNG)。
   - `黑底`:強制用亮度 max(r,g,b),把近黑當空白(適合火焰/魔法這類 **additive 黑底特效圖**,它們整張不透明、黑=透明,用 alpha 會完全失效)。
2. **② 切格**(僅大圖模式):載入時會**自動偵測並套用**格數,並自動切到 `原圖切格` 預覽,把**偵測到的格線疊在原圖上**(青色切線 + 每格橘色內容裁切框)讓你一眼核對是否切對。也可手動改 `列 Rows × 行 Cols` 或按 `🔍 自動偵測格線` 重算,格線即時更新。
   - **切格區域**(可展開):可設定 `起點 X/Y` 與 `總寬/總高`,調整整個 grid 的位置與尺寸。適合圖集有外邊距、或寬高非整除格數需要微調對齊時。預覽中以**黃色外框**標示可調區域,`↺` 可重設為整張圖。
   > 自動偵測用**頻域法**(見下),連火焰/煙霧這類軟邊、彼此暈開、沒有空白分隔的動畫表也能抓對。會顯示可信度(高/中/低),低可信度時請肉眼核對。
3. **③ 重排模式**
   - **連續圖(等大 cell)**:動畫用。**保留每格內部布局**,只削掉所有 frame 共同的空白邊。
     > 做法:對每個 cell 的四邊量「可剃除距離」(cell 邊到內容邊的空白),取所有 cell 每邊的**最小公共值**當共同裁切量,再用同一個矩形裁掉每一個 cell。因為每格削掉的量完全相同,內容的相對位置不變 → **單格播放不會跳位**。這等價於「所有內容框在 cell 內座標的聯集」。切勿改成各自置中——那會破壞布局。
     > 在 `原圖切格` 預覽會畫出**綠色共同保留框**(每個 cell 都一樣),綠框與青色格線之間就是被共同剃除的空白。
   - **整併(最小 gap)**:雜項資源整併用。每張各自裁到最小外框,再用 **MaxRects** 裝箱,面積最省。
4. **④ 參數**:Alpha 裁切閾值、cell 間距 gap、輸出每列數、最大寬度、POT 貼齊、1px 擴邊(防接縫)。
5. **⑤ 輸出**:`下載 PNG` + `下載 JSON metadata`。

預覽區可切 `結果` / `原圖切格` 兩種檢視,並勾選:`顯示 cell 框`(青色切格線)、`顯示裁切框`(橘色各格內容範圍)、`顯示省去空白範圍`(以**紅色 50% 半透明**填色標出每個 cell 四邊會被共同剃除的空白 = cell 框與共同保留框之間那圈)。底部即時顯示:輸出尺寸、cell 數、**填充率**、**面積節省 %**。

所有邊框(格線 / 裁切框 / 結果邊線 / 區域框)畫在**獨立的螢幕解析度覆蓋層**上,不隨影像一起被縮放,線寬固定為螢幕像素 → 任何縮放(尤其 <1)都清晰、不會忽粗忽細或消失。

**預覽 Viewport 操作**:
- 滑鼠**滾輪**:對準游標縮放。
- **拖曳**:平移。
- **雙擊**或右上角 `Fit`:縮放至適合視窗並置中(載入圖片時也會自動 Fit)。
- 右上角縮放框可**直接輸入數值**(小數點後 2 位),滑桿同步。

**動畫預覽面板(右側)**:逐格播放連續圖,驗證動畫表現。
- 播放 / 暫停、FPS(1–60)、逐格 scrubber、循環開關、底色(棋盤 / 深 / 淺)。
- 依 frame 的 `index` 順序播放,並**還原每格內容在原始 cell(sourceSize)的位置**——所以能直接看出有沒有跳位(驗證連續圖模式的布局保留)。

## 兩種模式的差別(為什麼要分)

| | 連續圖 uniform | 整併 pack |
|---|---|---|
| cell 大小 | 全部一致 | 各自最小 |
| 適用 | 逐格動畫 / 時間軸取樣 | 無順序的資源打包 |
| 裁切依據 | 四邊可剃除距離的**最小公約**(= 聯集框) | 每張**自身**外框 |
| 目標 | 保留布局、去共同空白 | gap 最小、面積最省 |

連續圖之所以不能各自裁切/置中,是因為每格內容位置不同,單獨處理會讓播放時內容跳位。用「四邊可剃除距離最小公約」的統一框裁切,每格削掉的量完全相同,布局才不變。

## JSON metadata 格式

通用格式,類 TexturePacker,方便自行接引擎:

```json
{
  "meta": { "app": "AtlasForge", "mode": "uniform|pack",
            "image": "atlas.png", "size": {"w":844,"h":388},
            "gap": 2, "trimAlphaThreshold": 10, "generated": "..." },
  "frames": [{
    "filename": "sample_0",
    "index": 0,
    "frame":            { "x":0, "y":0, "w":139, "h":128 },  // 在新圖集的位置與尺寸
    "rotated": false,
    "trimmed": true,
    "spriteSourceSize": { "x":6, "y":4, "w":126, "h":120 },  // 內容相對原始 cell 的偏移
    "sourceSize":       { "w":170, "h":170 },                // 原始 cell 尺寸
    "pivot":            { "x":0.5, "y":0.5 }
  }]
}
```

- `frame`:切這塊貼圖。
- `spriteSourceSize` + `sourceSize`:還原 pivot / 對齊用(反算內容在原始格內的位置)。
- 連續圖模式所有 frame 的 `frame.w/h` 一致;整併模式各自不同。

## 批次 / 自動化

頁面載入後會掛上 `window.AtlasForge`,可用 console 或腳本呼叫:

```js
await AtlasForge.loadFromURLs(['/path/a.png']);  // 同源載入並處理
AtlasForge.state.packMode = 'pack';
AtlasForge.process();
AtlasForge.state.result;   // { canvas, frames, w, h, ... }
```

## 技術

- 無任何外部相依,單檔 `index.html`。
- 裝箱:MaxRects(Best Short Side Fit)。
- 裁切:依 alpha 閾值求 bounding box。
- **自動偵測格線(頻域法)**:規則圖集的內容沿 X/Y 軸以固定間距重複,在 alpha 投影上是週期訊號。
  1. 對每軸的 alpha 投影做**線性去趨勢**(移除整體漸暗/漸亮,避免洩漏到低頻)。
  2. 逐一計算 `c = 1..N/24` 個週期的 DFT 強度。
  3. 強度最高的 `c` 就是該軸真正的 cell 數;峰值突出度作為可信度。

  這比「找空白分隔帶」穩健得多——後者遇到彼此暈開、沒有空隙的 VFX 會整個失效(偵測成 1×1)。
  已用 15 組不同尺寸/格數的合成測試 + 真實透明煙霧圖 + 真實黑底火焰圖(5×5)驗證通過。
  預設最小 cell 邊長 24px(可在 `autoDetectGrid(src, minPitch)` 調整)。
  偵測前會先用 `resolveBg` 判斷背景型態,投影訊號改用對應的內容值(alpha 或亮度),
  所以**透明背景與不透明黑底兩種圖都能偵測**。
